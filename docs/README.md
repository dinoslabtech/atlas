The prior draft is the private repo `dinoslabtech/dinoslab-kicad-libs`. Detailed field sections in the three passive docs are the working draft. YAML is the machine encoding of that attempt. Where they disagree, Atlas keeps the disagreement visible rather than deleting a class to force a match.
