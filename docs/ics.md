# ICs

Source: `dinoslabtech/dinoslab-kicad-libs` `docs/NOMENCLATURE.md`, family list only.

Key `IC`. Field order is not decided. The class ships with zero fields. The taxonomy editor is how fields get specified.

NOMENCLATURE examples such as `IC LM358 SOIC8` are a reminder of the family, not a field template for Atlas v1.
